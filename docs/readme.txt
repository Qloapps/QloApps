PREPARATION
===========

To install QloApps, you need a remote web server or on your computer (MAMP), with access to a database like MySQL.
You'll need access to phpMyAdmin to create a database and to indicate the information in the database in the installer.

You can find the requirements needed to run QloApps from the following link:
https://devdocs.qloapps.com/introduction/requirements.html#hosted-server-configurations

INSTALLATION
============

1. You can install QloApps easily after downloading QloApps. There are easy steps for the installation process. Please visit QloApps Installation Guide and follow the steps for the successful installation.

2. Or you can install QloApps with docker image. For the docker image of QloApps, please visit Dockerize image of QloApps(https://hub.docker.com/r/webkul/qloapps_docker)

Docker pull command: docker pull webkul/qloapps_docker
